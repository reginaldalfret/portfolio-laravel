### 4. Prerequisites & Local Development

#### Prerequisites
- PHP 8.2+ (PHP 8.4 recommended) with mbstring, pdo, xml

#### Installation
```bash
git clone https://github.com/reginaldalfret/portfolio-laravel.git
cd Portfolio-Laravel
composer install
```

#### Running Development Server
```bash
php artisan serve --host=0.0.0.0 --port=8000
```

#### Production Build
```bash
composer install --no-dev -o
```

#### Running Test Suite
```bash
php artisan test
```
