# Reginald Alfret V — Resume Portfolio (Laravel 11/12 & PHP 8.4)

Modern obsidian liquid-glass resume portfolio engineered with **Laravel 11/12**, **PHP 8.4**, **Blade Templating**, and **Tailwind CSS**.

Parallel implementation of the production portfolio at [**reginaldalfret.tech**](https://reginaldalfret.tech).

---

## ⚡ Tech Stack

- **Framework**: Laravel 13 (v13.40 / Laravel 11/12 standard)
- **Language / Runtime**: PHP 8.4.24
- **Templating**: Laravel Blade Server-Side Rendering
- **Server**: Artisan Built-in Server (`php artisan serve`)
- **Styling**: Tailwind CSS (Liquid-Glass Obsidian Design System)
- **Dependency Manager**: Composer

---

## 🚀 Getting Started

### Prerequisites

- PHP 8.4+ (`php -v`)
- Composer (`composer --version`)

### Install Dependencies & Run

```bash
# Clone the repository
git clone https://github.com/reginaldalfret/portfolio-laravel.git
cd portfolio-laravel

# Install dependencies (if not cloned with vendor)
composer install

# Copy environment & generate key
copy .env.example .env
php artisan key:generate

# Start the local development server (port 8083)
php artisan serve --port=8083
```

Open [http://localhost:8083](http://localhost:8083) in your browser.
